## Mejora aplicada

Se mejoró el formulario para marcar los campos con error usando `aria-invalid` y llevar el foco al primer campo inválido.

### ¿Qué se cambió?

- Se agregó una validación visual y accesible sobre los campos incorrectos.
- Se limpió el estado de los campos al enviar o reiniciar el formulario.
- Se enfocó automáticamente el primer campo con error para corregirlo más rápido.

### ¿Por qué se cambió?

- Para hacer más fácil la corrección de errores.
- Para mejorar la experiencia del usuario.
- Para reforzar la accesibilidad del formulario.

## Resultado

La mini-solución quedó más clara y fácil de usar cuando hay errores de entrada.
